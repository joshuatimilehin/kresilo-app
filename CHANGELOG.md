# Changelog

## Versioning

- The app follows semantic versioning in `package.json`. While the version is below 1.0.0, a minor bump marks a set of user-visible features and a patch bump marks fixes.
- Planned and live data models are versioned one by one in `src/models` (`docs/models.manifest.json` is generated from them). Storage changes are additive numbered migrations in `db/migrations`, run by the owner.
- Every entry below names the pull request and the issue that owns it.
